A modern, responsive, and feature-rich hospital management dashboard built with React, Vite, and Tailwind CSS. It integrates Google Generative AI for advanced analytics and features a robust Firebase backend.

## ✨ Features
- **Patient Management:** Streamlined workflow for admitting, monitoring, and discharging patients.
- **Analytics & Insights:** Visualized data metrics powered by Recharts.
- **AI-Powered Diagnostics:** Utilizing `@google/generative-ai` for cutting-edge clinical risk assessment.
- **Modern UI/UX:** Clean and intuitive interface designed with Tailwind CSS and Lucide Icons.
- **Real-time Data:** Seamless integration with Firebase for real-time updates and data storage.

## 🛠️ Tech Stack
- **Frontend:** React 19, React Router v7
- **Styling:** Tailwind CSS, CLSX, Tailwind-Merge
- **Charting:** Recharts
- **Icons:** Lucide React
- **Backend/BaaS:** Firebase
- **AI Integration:** Google Generative AI (Gemini)
- **Build Tool:** Vite
- **Language:** TypeScript / JavaScript

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
Start the development server:
```bash
npm run dev
```

### Building for Production
```bash
npm run build
```
